# 03 — Násobilka

Napiš skript, který načte číslo a vypíše jeho násobilku od 1 do 10, zarovnanou
do sloupců (víš to už z předchozího tématu).

## Požadavky

- Použij `for` cyklus s `range()`.
- Výstup zarovnej pomocí formátovacího mini-jazyka, např.:

```
Zadej číslo: 7
 7 x  1 =  7
 7 x  2 = 14
 7 x  3 = 21
 7 x  4 = 28
 7 x  5 = 35
 7 x  6 = 42
 7 x  7 = 49
 7 x  8 = 56
 7 x  9 = 63
 7 x 10 = 70
```

(všimni si, že `1` i `10` mají číslice zarovnané doprava na stejnou šířku)

## Bonus

- Přidej druhý `for` cyklus okolo prvního a vypiš násobilky pro čísla 1 až 10
  (deset tabulek pod sebou, oddělených prázdným řádkem nebo čárou).
