# Cvičení

Každé cvičení má vlastní složku `NN-nazev-ukolu/`:

```
01-nazev-ukolu/
├── README.md         # zadání
├── solution/
│   └── main.py       # prázdný stub, řešení píšeš sem
└── reference/         # přibude až po dořešení, Claudovo referenční řešení
    └── main.py
```

Číslování `NN-` udává doporučené pořadí (rostoucí obtížnost).
